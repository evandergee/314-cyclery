# 314 Cyclery (demo)

A demo website for a **fictional** St. Louis bike shop, built to show what a small bike shop's site could do. All bikes, prices and stock counts are sample data.

## Why

Many local bike shops have websites where you can't tell what's actually in stock, so customers have to call or drive over. This demo puts live inventory first.

## Features

- **Bikes in stock:** filter by type, size and price, with stock counts per frame size and "only 1 left" labels.
- **Reserve for pickup:** hold a bike in your size for 48 hours, no payment needed.
- **Book service:** pick a package and a drop-off day with open slots.
- **Size guide:** enter your height to get a likely frame size, then jump to bikes in that size.
- **Group rides, hours and an "open now" indicator.**
- **Owner view:** bookings, reservations, low-stock sizes to reorder, and drop-offs by day.

In a real shop, the inventory would sync from the point-of-sale system (for example Lightspeed, which many bike shops use).

## Run it

It's a single `index.html` file with no build step. Open it in a browser.
